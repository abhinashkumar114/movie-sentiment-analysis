# Movie Sentiment Analysis

This is my first AI project.  
It predicts whether a movie review is **Positive** or **Negative** using Machine Learning.

## What I Used
- Python
- Scikit-learn
- Logistic Regression
- TF-IDF Vectorizer

## How it Works
1. Takes a movie review as input
2. Converts the text into numbers
3. Predicts the sentiment (Positive or Negative)

## Results
- Trained a simple Logistic Regression model
- Basic accuracy achieved on sample data

## How to Run
1. Open the notebook in Google Colab
2. Run all the cells
3. Test with your own movie review
